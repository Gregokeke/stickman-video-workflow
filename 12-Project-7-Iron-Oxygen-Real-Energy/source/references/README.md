The three distinct reference concepts used for the generated artwork were 01, 03 and 04. Attach actual image files to each new ImageGen request and explain what each contributes. Prefer distinct concepts over three near-duplicates. Generate original script-specific poses and props rather than copying a complete reference layout.

The black backing in these JPGs is a preview background. Finished videos use a white canvas with inward edge shadows. New production illustrations require true transparency, predominantly red shapes, black expression/contour details and no baked captions.

After extracting the outer workspace, extract this visual-reference ZIP into `04-Workflow-and-Animation/` to place this `references/` directory beside the workflow. Copy it into new production projects as needed. The original motion reference video is included separately in `01-Original-Video-Reference/`.
