# Bouncy Animation Study

## Start here

1. Watch `Bouncy-UI-3D-Demo.mp4` for the improved 22-second, three-scene dimensional sample.
2. Watch `Bouncy-Reference-Compilation.mp4` for the three major source examples together (about 20.27 seconds).
3. Read `Bouncy-UI-Animation.md` for the detailed reference study and core motion recipes.
4. Read `Bouncy-UI-3D-Addendum.md` for the new materials, choreography, scene plan and clip provenance.

## Included material

- Improved sample: 1080 × 1920, 60 fps, H.264/AAC.
- Three individual source clips: 576 × 1024, 30 fps, original source picture and audio.
- One compilation of those source clips, in chronological order.
- Editable HTML/GSAP project with local font, runtime and generated effects.
- Original nine-second sample for before/after comparison.
- Composition check report and media verification metadata.

The source clips are extracts of the supplied reference video. They retain its existing watermark and are clearly separated from the newly authored demonstration. The source ranges are documented in the addendum. The compilation uses direct cuts to keep the original motion speed and timing intact.

For editing and re-rendering, open `editable-project/README.md`. The raw HTML uses a paused timeline; run the HyperFrames preview to play or scrub. The third scene is an original rhythm sculpture and is separate from the reference-derived clock and time-card studies.
