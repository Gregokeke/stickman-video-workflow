# Walking — The Magic Pill (visual hierarchy revision)

1080 × 1920, 30 fps, 125.1 seconds. 52 distinct generated illustrations plus a mirrored presenter placement across 59 meaningful appearances.

Run `npm ci`, then `python3 build.py`. Set `CHROME_PATH` to Chromium if it is not already in the supported cache or system location. Run `node render.mjs` to export. Python requires Pillow and NumPy; FFmpeg must be installed.

The original narration edits and caption timings are preserved. `storyboard.json` defines deliberate appearance spans and custom layouts. `animation.js` defines held acting, comparisons and center/side/return choreography. `REVISION-NOTES.md` explains the current revision. `WORKFLOW.md` and `DESIGN.md` retain the approved visual rules.

The final iterations add a generated happy-pill-taking pose, an editable hypothetical risk-index example, the opening hourglass and the specifically requested restored research/leg/bottle scenes.
